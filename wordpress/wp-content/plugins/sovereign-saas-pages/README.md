# Sovereign SaaS Pages for Nexros

Purpose:
- SaaS dashboard
- tenant onboarding
- affiliate center
- wallet center
- SaaS landing page

Activation:
1. Copy `nexros-child` to `wp-content/themes/nexros-child`
2. Copy `sovereign-saas-pages` to `wp-content/plugins/sovereign-saas-pages`
3. Activate `Nexros Child`
4. Activate `Sovereign SaaS Pages for Nexros`
5. Open `SaaS Pages` in wp-admin and set:
   - API Base URL
   - JWT Shared Secret
   - Tenant ID
   - Caller ID
   - Workspace ID
